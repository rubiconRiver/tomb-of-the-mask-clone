# Generate Level 1 Thumbnail

## Quick Instructions

To create a thumbnail for level 1 that shows in the main menu:

1. **Open the level editor**
2. **Load the level**: Click Load button and select `001.json`
3. **Save with thumbnail**: Click Save button → Save As → Enter "001" → Select "Main Levels" → Save As
4. **Done!** The thumbnail will automatically be generated

## What the thumbnail shows:

- **Bright white blocks** = walls from the level
- **Dark blue background** = empty space  
- **Clean, simple pattern** that's easy to recognize
- **Minimum 2x2 pixels per block** for visibility
- **Centered in 128x128 image** with small border

## The improved thumbnail generation:

- High contrast (bright white on dark blue)
- Minimum cell sizes to ensure visibility  
- Only shows walls (no coins/spawn/goals for simplicity)
- Perfect miniature replica of the level structure

The thumbnail will appear in the main menu as the Level 1 button background, making it easy to recognize the level layout at a glance!
