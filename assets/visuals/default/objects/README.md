# Objects Assets

This directory contains visual assets for the **objects** category.

## Required Files

- **coin.png** - Collectible coins that give points
- **goal.png** - Level goal/finish line
- **player.png** - Player character sprite
- **player_spawn.png** - Starting position indicator

## Asset Requirements

- **Format**: PNG with transparency support
- **Color depth**: 32-bit RGBA
- **Recommended sizes**:
  - coin.png: 32x32 pixels
  - goal.png: 64x64 pixels
  - player.png: 48x48 pixels
  - player_spawn.png: 64x64 pixels

## Usage

Place your custom PNG files in this directory to override the default objects visuals.
The game will automatically load these assets when using this theme.

## How to Add Your Custom Assets

1. Create your coin image (32x32 pixels) and save as `coin.png`
2. Create your goal image (64x64 pixels) and save as `goal.png`
3. Create your player character (48x48 pixels) and save as `player.png`
4. Create your spawn point marker (64x64 pixels) and save as `player_spawn.png`
5. Place all files in this directory
6. The game will automatically use your custom visuals!
