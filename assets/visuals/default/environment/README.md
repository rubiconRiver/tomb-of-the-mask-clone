# Environment Assets

This directory contains visual assets for the **environment** category.

## Required Files

- **background.png** - Main game background (tiles across screen)
- **wall.png** - Solid wall blocks that stop player movement

## Asset Requirements

- **Format**: PNG with transparency support
- **Color depth**: 32-bit RGBA
- **Recommended sizes**:
  - background.png: 256x256 or larger (will tile)
  - wall.png: 64x64 pixels

## Usage

Place your custom PNG files in this directory to override the default environment visuals.
The game will automatically load these assets when using this theme.

## How to Add Your Custom Assets

1. Create your background image (256x256 or larger) and save as `background.png`
2. Create your wall block image (64x64 pixels) and save as `wall.png`
3. Place both files in this directory
4. The game will automatically use your custom visuals!
