# Effects Assets

This directory contains visual assets for the **effects** category.

## Required Files

- **particle.png** - Small particle effect sprite
- **explosion.png** - Explosion effect sprite

## Asset Requirements

- **Format**: PNG with transparency support
- **Color depth**: 32-bit RGBA
- **Recommended sizes**:
  - particle.png: 16x16 pixels
  - explosion.png: 64x64 pixels

## Usage

Place your custom PNG files in this directory to override the default effects visuals.
The game will automatically load these assets when using this theme.

## How to Add Your Custom Assets

1. Create your particle sprite (16x16 pixels) and save as `particle.png`
2. Create your explosion sprite (64x64 pixels) and save as `explosion.png`
3. Place both files in this directory
4. The game will automatically use your custom visuals!
