# UI Assets

This directory contains visual assets for the **ui** category.

## Required Files

- **button.png** - UI button background
- **panel.png** - UI panel background

## Asset Requirements

- **Format**: PNG with transparency support
- **Color depth**: 32-bit RGBA
- **Recommended sizes**:
  - button.png: 128x64 pixels
  - panel.png: 256x256 pixels

## Usage

Place your custom PNG files in this directory to override the default ui visuals.
The game will automatically load these assets when using this theme.

## How to Add Your Custom Assets

1. Create your button background (128x64 pixels) and save as `button.png`
2. Create your panel background (256x256 pixels) and save as `panel.png`
3. Place both files in this directory
4. The game will automatically use your custom visuals!
